Privacy

This site sets no cookies, writes nothing to your browser's storage, and runs no analytics. There is no form on it, so there is nothing for you to submit. Every file it loads comes from this domain: no fonts, scripts or images are fetched from anywhere else.

The site is hosted on GitHub Pages. Serving a page means GitHub sees the request, and it records the visitor's IP address in its server logs for security. That processing is GitHub's, set out in the GitHub Privacy Statement. I cannot reach those logs and get no report from them.

All previews run entirely inside your browser. Whatever you type or drag stays in the page's memory, is never sent anywhere, and is gone the moment you reload.

The links elsewhere on this site lead to GitHub, which runs by its own rules, and this note stops at that boundary.
